# 🔎 API Debugger

**A tool that helps with testing API endpoints. Made using React + Typescript + Vite + Tailwind CSS**

---

## 🔧 Features

- Send GET and POST requests
- Get instant feedback and measure endpoint response performance
- Save requests to re-use or replay in the future

---

## 🛡️ Privacy Policy

This app stores settings **locally on your browser** using localStorage.  
No data is collected, tracked, or sent anywhere and does not leave your device.
